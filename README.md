Sistema Informático para Mejorar el Proceso de Venta de la Bodega El Profe

La bodeguita “El Profe” actualmente no cuenta con un sistema de gestión para 
administrar sus procesos de venta y control de productos, por lo que estas 
actividades se realizan de manera manual. Esta forma de trabajo genera 
diversos riesgos, como la pérdida de información, la duplicidad y las 
inconsistencias en los registros, además de dificultar el conocimiento del stock 
disponible y el seguimiento actualizado de los productos. El principal problema 
identificado es la ausencia de mecanismos que permitan gestionar de manera 
eficiente la información de productos y ventas. Esto provoca que tareas 
cotidianas, como la búsqueda de artículos, la verificación de existencias y la 
identificación de productos que requieren reposición, demanden mayor tiempo 
y esfuerzo. 

El sistema estará dirigido inicialmente a la persona encargada de administrar y 
atender la bodeguita, quien utilizará la aplicación para registrar las operaciones diarias 
y consultar la información necesaria para sus actividades. La información se almacenará en una base de datos 
centralizada para mantener la consistencia de los registros y facilitar su consulta. Como resultado, se espera 
disponer de una herramienta informática que contribuya a organizar las ventas, mejorar el seguimiento de los productos, 
identificar oportunamente las necesidades de reposición y facilitar la planificación de compras. 
Este proyecto se enfocará en los procesos internos de una sola bodeguita y no comprenderá, en su versión inicial, 
la integración con sistemas bancarios, plataformas de comercio electrónico, facturación electrónica ni la administración 
de múltiples establecimientos.
